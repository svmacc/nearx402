What this public page can and cannot see

Everything on this page is public chain data. Anyone could build it.

Public on NEAR

  • The recipient and amount of every payment. Token transfers are transparent.
  • The time and paying agent of each payment.
  • The recipient and amount of a rejected attempt, from its transaction arguments.
  • A daily total anyone can add up, which is a lower bound on the cap.

Not on chain

  • The daily cap and the per-call limit.
  • Allowed vendors that have not been paid yet.
  • Which rule a rejected attempt broke: the log says only "invalid proof".

The agent must hold the policy to prove it, so a compromised agent can read it, but it still cannot break it.
